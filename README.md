# Humble CV Creator

A CV builder that runs entirely in your browser. Type in the form on the left, the A4 page on the right updates as you go and when you're happy you hit print and get a PDF. Nothing gets uploaded anywhere, everything just saves to localStorage so your CV is still there next time.

**[Try it here](https://humble-cv-creator.pages.dev)**

Six sections (general info, skills, projects, work experience, education, languages), each with add/remove entries. There's a Load Example button if you want to see what it looks like filled in.

## Stack

React, TypeScript, Vite, Tailwind

## Running it

```bash
bun install
bun run dev
```

Built as the React project from The Odin Project, with some extra bits bolted on.
